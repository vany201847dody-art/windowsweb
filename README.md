# Windows 11 Web (демонстрация в браузере)

Полноэкранная имитация Windows 11 в одном HTML-файле — без сервера и интернета.

## Возможности

- Рабочий стол, иконки, контекстные меню
- Меню «Пуск», поиск, панель задач, представление задач
- Проводник, «Этот компьютер», Блокнот, Терминал, Калькулятор, Корзина
- NovaBank: карты, переводы, оплата ЖКХ, автоплатежи, контакты
- QR-код, Диктофон, Заметки
- Игровой центр: Сапёр, Змейка, 2048, Память, Крестики-нолики
- Часы, Будильник, Таймер, Секундомер, Мировые часы
- Магазин, Камера, Фото, Музыка, Карты, Погода, Почта
- Параметры: персонализация, обои, тёмная/ночная тема

## Запуск

Просто откройте `index.html` в любом современном браузере.
